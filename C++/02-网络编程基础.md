# 网络编程基础

> 从零开始学习 C++ 网络编程，掌握 Socket API 与 TCP/UDP 通信。

## 核心概念速查

| 概念 | 说明 | 关键点 |
|------|------|--------|
| **Socket** | 网络通信端点 | 文件描述符抽象 |
| **TCP** | 面向连接、可靠 | 三次握手、四次挥手 |
| **UDP** | 无连接、不可靠 | 快速、轻量 |
| **sockaddr** | 通用地址结构 | IPv4/IPv6 统一接口 |
| **字节序** | 大端/小端转换 | `htons()` `htonl()` |

## TCP 三次握手 / 四次挥手

```
三次握手(建立连接):
  Client ──SYN────▶ Server
  Client ◀─SYN+Ack─ Server
  Client ──Ack────▶ Server

四次挥手(关闭连接):
  Client ──FIN────▶ Server
  Client ◀─Ack───── Server
  Client ◀─FIN───── Server
  Client ──Ack────▶ Server
```

## TCP 客户端-服务器模型

```
服务器: socket() → bind() → listen() → accept() → recv/send → close()
客户端: socket() → connect() → send/recv → close()
```

## 核心函数对照表

| 函数 | 用途 | 参数要点 |
|------|------|----------|
| `socket()` | 创建套接字 | `AF_INET, SOCK_STREAM, 0` |
| `bind()` | 绑定地址 | 套接字 + sockaddr_in |
| `listen()` | 监听连接 | backlog 队列长度 |
| `accept()` | 接受连接 | 返回新套接字描述符 |
| `connect()` | 发起连接 | 服务器地址 |
| `send/recv()` | 发送/接收数据 | 缓冲区 + 长度 |
| `htons/htonl()` | 主机→网络字节序 | short/long |
| `ntohs/ntohl()` | 网络→主机字节序 | short/long |

## 示例：简单 TCP 服务器

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>

int main() {
    // 1. 创建 socket
    int server_fd = socket(AF_INET, SOCK_STREAM, 0);

    // 2. 绑定地址
    sockaddr_in address{};
    address.sin_family = AF_INET;
    address.sin_addr.s_addr = INADDR_ANY;   // 监听所有网卡
    address.sin_port = htons(8080);
    bind(server_fd, (sockaddr*)&address, sizeof(address));

    // 3. 监听
    listen(server_fd, 5);

    // 4. 接受连接(阻塞,直到有客户端连入)
    sockaddr_in client_addr{};
    socklen_t addr_len = sizeof(client_addr);
    int client_fd = accept(server_fd, (sockaddr*)&client_addr, &addr_len);

    // 5. 收发数据
    char buffer[1024] = {0};
    recv(client_fd, buffer, sizeof(buffer), 0);
    std::cout << "收到: " << buffer << std::endl;

    send(client_fd, "Hello!", 6, 0);

    // 6. 关闭
    close(client_fd);
    close(server_fd);
    return 0;
}
```

## 常见坑

| 问题 | 原因 | 解决 |
|------|------|------|
| `Address already in use` | 服务器重启时 TIME_WAIT | `setsockopt(SO_REUSEADDR)` |
| `Connection refused` | 服务器未启动或端口错 | 检查服务器状态、端口 |
| 数据截断 / 粘包 | TCP 是字节流无边界 | 定义协议或按长度读取 |
| 阻塞卡死 | accept/recv 阻塞等待 | 多线程 / IO 多路复用 |
| 头文件缺失 | 平台差异 | `<sys/socket.h>` `<netinet/in.h>` |

## 顿悟

- **TCP 是字节流,不是消息流**:一次 send 不一定被一次 recv 完整收到,数据粘包是网络编程第一坑,需要自己定义消息边界。
- **accept 的返回值是新套接字**:监听套接字和通信套接字是两个描述符,一个服务器要并发,就得对每个 accept 出来的新 fd 单独处理(线程/进程/事件驱动)。
- **网络字节序是规定**:多字节整数在网络上统一大端,本地要转。
