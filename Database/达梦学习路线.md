# 达梦数据库学习路线（Qt/C++ 电力运维场景）

## 背景定位

- **行业场景**：电力设备运维。变电站/配电房内的各类设备通过 **IEC 104 规约报文**上送遥测（YC，如电流/电压）、遥信（YX，如开关位置）数据。
- **技术栈**：Qt/C++（Qtc++）开发上位机后台程序，接收并解析报文，将数据写入国产数据库 **达梦（DM8）**，界面用 Qt Model/View（MVC）框架展示。
- **教学方式**：数据库的使用讲解较详细，过程中**全程与 MySQL 对比**，帮助有 MySQL 经验的开发者快速迁移到达梦。
- **说明**：业务代码允许使用伪代码，重点讲解数据库连接、SQL、模型绑定等真实可用的代码。

## 学习路径建议

1. 先读 **01** 建立「报文 → 数据库 → 界面」的整体认识，理解 Qt MVC 与数据库模型如何协同。
2. 再补 **02 / 03** 打牢连接配置与 SQL 基础，熟悉达梦与 MySQL 的差异。
3. 进入 **04** 报文实战，深挖 IEC 104 规约解析与落库细节。
4. 最后看 **05** 进阶篇，面向生产运维（事务、备份、性能）。
