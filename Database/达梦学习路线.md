# 达梦数据库学习路线（Qt/C++ 电力运维场景）

## 背景定位

- 电力设备运维场景：变电站设备经 IEC 104 规约报文上送遥测/遥信数据，需要采集、解析并落库存储。
- Qt/C++ 开发背景（Qtc++）：以 Qt 技术栈（MVC、QSqlDatabase、ODBC）为主线承载数据库操作与界面联动。
- 国产数据库达梦（DM8）学习：从连接、SQL 到运维全链路，教学过程中与 MySQL 持续对比，突出差异。
- 业务代码可用伪代码表述，重点放在数据库讲解的详细性上（驱动、连接、语法、事务、运维）。

## 学习路径建议

- 先读 01 建立「报文→数据库→界面」整体认识，理解全链路数据流向。
- 再补 02/03 打牢连接与 SQL 基础，掌握 ODBC 驱动与达梦语法特性。
- 04 回到报文实战深挖规约，将解析与落库结合，完成闭环。
- 05 面向生产运维，覆盖事务、存储过程与备份恢复等工程落地能力。
