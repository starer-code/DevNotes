## 第一篇《01-Qt-MVC与达梦数据库集成》内容大纲

1. **场景背景**：电力设备运维 — 变电站设备经 IEC 104 规约上送遥测/遥信报文，Qt 后台接收解析后写入达梦，界面用 MVC 展示。
2. **达梦连接配置（详细）**：
   - Qt 无原生达梦驱动，走 ODBC（达梦自带 DM ODBC 驱动）。
   - 连接串格式、QSqlDatabase 建立流程。
   - 与 MySQL（QMYSQL 驱动）对比。
   - 达梦 `COMPATIBLE_MODE` 兼容 MySQL 语法说明。
3. **三种数据库 Model 详解**：`QSqlQueryModel`（只读）/ `QSqlTableModel`（单表读写）/ `QSqlRelationalTableModel`（外键关联）；与 MySQL 用法对比（Qt 屏蔽底层差异，两种库代码一致）。
4. **业务链路实现（伪代码 + 关键真码）**：
   - 104 报文接收 → 解析 → INSERT 落库 → `model->select()` 自动刷新界面。
   - `setEditStrategy` 编辑策略、排序、筛选、委托。
5. **与 MySQL 对比表**：连接方式/驱动/语法/字符集/事务/性能。
6. **常见坑**：ODBC 32/64 位与 Qt 位数匹配、达梦端口 5236、字符集 GBK/UTF-8、事务与锁。
7. **延伸阅读**：链接 `Qt/Qt_ModelView_MVC架构详解.md`（已有笔记，不重复 MVC 基础）。
